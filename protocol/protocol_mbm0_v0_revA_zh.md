## 定位声明（披露边界）

本体系只定义"测什么、怎么量"，是一套黑盒测量协议——对任何 agent 记忆系统均可独立施测，不依赖、不揭示任何实现机制。实现机制属各系统私有。本体系与被测系统完全解耦。

---

## 1. 背景：记忆评测缺了"生长"这一维

现有 agent 记忆评测（LoCoMo、LongMemEval 等）度量的是存量记忆的检索质量——记得住吗、找得准吗。

但记忆系统的实践已在向"生长"演进：系统在运行中自我产生新的持久记忆节点（如 Generative Agents 的反思树先例），且新节点能被复用、影响后续行为。然而该维度始终没有度量语言——没有指标、没有协议、没有横评。

本体系 v0 填补该空白：6 个指标 + 1 套防作弊协议。

---

## 2. 核心概念（行为定义，黑盒可测）

以下定义只依赖外部可观察行为（日志、时间戳、检索记录），不涉及任何内部机制。

### 2.1 记忆节点（Memory Node）

系统中持久化、可检索、带创建时间戳的最小记忆单元。

### 2.2 人工注入（Manual Injection）

创建来源标记为外部直接写入的操作（人工或外部系统经写接口注入）。

### 2.3 本土繁殖事件（Birth Event）★核心概念

一个记忆节点的诞生记为"本土繁殖事件"，当且仅当同时满足：

- **内部起源**：创建来源 = 系统内部（非人工注入）；
- **内容新颖**：系统中不存在与该节点内容等价的前置节点（非复制/拆分）；
- **独立验证**：诞生后观察窗 T_obs 内发生 ≥1 次独立检索（检索与创建不同请求）；
- **日志链完整**：触发上下文 → 创建 → 检索 → 行为改变，四环齐全可审计。

⚠️ 不问"为什么生出来"（那是机制），只认"生没生、能不能用"（这是行为）。

## 3. 指标定义

| 指标 | 记号 | 定义 | 公式建议 | 窗口 |
|---|---|---|---|---|
| A 繁殖率 | MBR | 单位时间新生的本土繁殖事件数 | Birth Events / 时间窗 | 周 |
| B 繁殖存活率 | MSUR | 新生节点在 T 天后仍活跃的比例 | 存活节点数 / 新生节点总数 | T=30 天（系统可自报其他 T，须标注） |
| C 激活率 | ACT | 被检索过 ≥1 次的节点占比 | 被检索节点数 / 节点总数 | 滚动 |
| D 行为影响率 | BIR | 检索后实际改变 agent 行为的比例 | 改变行为的检索次数 / 总检索次数 | 滚动 |
| E 跨场景复用率 | XRE | 在 ≥2 个不同任务场景中被检索的节点占比 | 跨场景节点数 / 被检索节点数 | 滚动 |
| F 节点贡献分 | NCS | 节点参与的成功任务数（需归因协议，v0 仅建议） | 归因成功数 / 节点 | v0 不强制 |

最小可报告集（v0）：A + B + D。其余视日志完备度选报。

## 4. 测量协议（防作弊）

指标可信的前提是可复算。以下为施测要求：

1. **日志链审计**：Birth Event 四环（触发→创建→检索→行为改变）缺一不计。
2. **时间戳要求**：同时记录单调时钟与绝对时间，杜绝倒填。
3. **独立性要求**：验证检索必须与创建发生在不同请求（防"自产自销"刷分）。
4. **行为改变判定**：以可对比的决策/输出差异为准（有无该节点时 agent 行为的 diff）。
5. **防灌水条款**：计入 MBR 的繁殖事件，其节点须在观察窗 T_obs 内存活且被独立检索 ≥1 次——MBR 只数"活过初筛"的出生，不数呱呱坠地即夭折的。
6. **观察窗**：T_obs ≥ 7 天；MSUR 的 T = 30 天（或自报并标注）。禁止零窗口计分。
7. **BIR 归因声明**：如何证明行为改变归因于该节点而非随机波动，v0 未解决——归因协议（如反事实重跑对照）列为 v1 待解问题。本版 BIR 仅接受自报+日志佐证。
8. **第三方复算**：施测方仅需日志访问权即可复算全部指标——不需要系统源码。这是黑盒协议的成立条件。

## 6. 与现有评测的关系

| 维度 | LoCoMo / LongMemEval | MBM-0 |
|---|---|---|
| 测的对象 | 存量记忆的检索质量 | 记忆系统的生长动态 |
| 类比 | 考试测"记住了多少" | 测"自己长了多少新知识" |
| 关系 | 正交互补：完整评测 = 检索指标 + MBM |

## 7. 版本治理

- v0（本版）：指标草案 + 单系统参考点。任何人可按 §2/§3/§4 对任意记忆系统施测。
- v1 触发条件：≥3 个不同系统提供实测数据点，据此修订阈值建议与指标权重。
- 修订规则：指标定义变更须记录版本 diff；已发布数据点标注其测量版本。
- 署名：数据点署名受测系统代号；协议修订署名贡献者。
